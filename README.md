# Microstrip patch antenna, 2.4 GHz

Line/inset-fed microstrip patch antenna designed in CST Studio Suite for the 2.4 GHz ISM band.

## Simulation

S-parameters and VSWR checked across multiple mesh refinement passes for consistency.

## Results

S11 = -11.3 dB at 2.4 GHz. VSWR ≈ 1.75 at resonance.

## Files

- s11.s1p - exported S-parameter data (Touchstone format)
- s11_plot.png - S11 magnitude vs frequency
- vswr_plot.png - VSWR vs frequency
- geometry.png - model view from CST

Tool: CST Studio Suite.
